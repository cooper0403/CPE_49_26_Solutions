# CPE_49_26_Solutions

## 專案介紹

這是我的個人 CPE 公開解題紀錄。實作代碼使用 C++ 撰寫，並搭配繁體中文的題目說明與解題解析，記錄解題思路與實作方式。

## 題單

本專案分為兩份題單：

| 題單 | 題數 | 說明 |
|---|---|---|
| CPE 49 | 49 題 | 舊題單 |
| CPE 26 | 56 題 | 2027 年開始啟用的新題單 |

## 每題內容

每題包含以下三個部分：

- **題目說明**：整理題意、輸入與輸出要求。
- **解題方案**：說明解題思路、演算法與注意事項。
- **實作代碼**：提供使用 C++ 撰寫的解答程式。

## 測試環境

- **測試環境**：CPE 使用的瘋狂程設。
- **編譯器**：MinGW GCC 6.3.0。
