# UVa 10101 — Bangla Numbers

## 題目連結

- [UVa 10101 - Bangla Numbers](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&category=13&page=show_problem&problem=1042)

## 題意摘要

給定一個非負整數 `N`，將它轉換成使用 Bangla 數字單位的表示方式。

使用的單位由大到小為：

- `kuti`：10000000（千萬）。
- `lakh`：100000（十萬）。
- `hajar`：1000（千）。
- `shata`：100（百）。

例如 `23764` 會表示成 `23 hajar 7 shata 64`。若 `kuti` 前面的數字仍然很大，也要繼續使用相同規則轉換。

## 輸入說明

1. 每筆測資輸入一個非負整數 `N`。
2. `0 ≤ N ≤ 999999999999999`，最多十五位數。
3. 持續讀取直到檔案結束（EOF）；`0` 也是需要處理的測資。

## 輸出說明

對每筆測資輸出一行轉換結果：

- 測資編號從 `1` 開始，靠右對齊、至少占四格，再接上一個句點 `.`。
- 句點後接一個空格與轉換結果，數字和單位之間以一個空格分隔。
- 數量為零的單位不輸出；若整個輸入為 `0`，轉換結果為 `0`。
- 每筆測資輸出完畢後換行。
