# 解決方案

因為題目輸入最多可達十五位數，所以使用 `long long` 儲存數字。

將數字由大到小拆成 `kuti`（10000000）、`lakh`（100000）、`hajar`（1000）與 `shata`（100），使用整數除法取得各單位的數量，再用取餘數繼續處理剩下的部分。

其中 `kuti` 前面的數字也可能需要使用這些單位表示，所以使用遞迴處理。

## 具體操作：

使用 `while(cin >> num)` 讀取每筆測資，直到檔案結束（EOF）。每讀取一筆就將 `cas` 加一，並使用 `setw(4)` 讓測資編號靠右對齊、至少占四格，再輸出句點。

若輸入為 `0`，直接輸出 ` 0`；否則呼叫 `fun(num)` 進行轉換。

在 `fun` 中，依照以下順序處理：

1. 若 `num >= 10000000`，先呼叫 `fun(num / 10000000)` 輸出 `kuti` 前面的數字，再輸出 ` kuti`，最後令 `num %= 10000000`。
2. 若剩下的 `num >= 100000`，輸出 `num / 100000` 與 ` lakh`，再令 `num %= 100000`。
3. 若剩下的 `num >= 1000`，輸出 `num / 1000` 與 ` hajar`，再令 `num %= 1000`。
4. 若剩下的 `num >= 100`，輸出 `num / 100` 與 ` shata`，再令 `num %= 100`。
5. 若最後 `num > 0`，輸出剩下的數字。

各段輸出前都加上一個空格，每筆測資處理完後換行。例如 `23764` 會轉換成 `23 hajar 7 shata 64`。

## 複雜度

設 `n` 為輸入數字的十進位位數。

- **時間複雜度：O(n)**。每次遞迴將數字除以 10000000，相當於減少七位數；每層只需固定次數的判斷與運算。

- **空間複雜度：O(n)**。遞迴呼叫需要堆疊空間，深度與數字位數成正比。

在本題最多十五位數的限制下，遞迴最多只有三層，因此時間與額外空間也可視為固定上限的 **O(1)**。

## 備註：

輸入 `0` 是有效測資，不是結束條件；但轉換過程中數量為零的單位不需要輸出。

多個單位可能同時出現在答案中，所以程式使用獨立的 `if` 依序處理，不能改成互斥的 `else if`。

`kuti` 可以重複出現。例如 `100000000000000` 會輸出成 `1 kuti kuti`，這也是需要遞迴處理的原因。
