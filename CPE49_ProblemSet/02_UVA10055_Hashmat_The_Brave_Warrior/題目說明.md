# UVa 10055 — Hashmat the Brave Warrior

## 題目連結

- [UVa 10055 — Hashmat the Brave Warrior](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&page=show_problem&problem=996)

## 題意摘要

Hashmat 是一個勇敢的將軍，他在打戰之前會計算己方與敵方的士兵數量差距，以此決定打與不打。

## 輸入說明

每筆測資有一行。

每行有兩個整數，代表 Hashmat 與敵方的士兵數量。

## 輸出說明

輸出兩者士兵數量的差（必定為正數或0）。
