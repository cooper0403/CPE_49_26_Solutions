# 解決方案

因為每個輸入字元都有固定的鍵盤對應位置，所以可以先建立 `map<char, char>`，將編碼字元作為 key，鍵盤同一列左邊第二個位置的字元作為 value。

輸入可能包含大寫字母，因此先使用 `tolower` 轉成小寫，再查詢對照表。空格則直接對應到空格，保留原本的單字間隔。

最後逐一輸出每個字元的對應值，就能完成解碼。

## 具體操作：

先建立 `map<char, char> mp`，手動加入各字元的對應關係，例如 `k` 對應 `h`、`[` 對應 `o`、`r` 對應 `w`，並加入空格對應空格的項目。

使用 `while(getline(cin, str))` 讀取完整一行文字，直到檔案結束（EOF）。`getline` 可以保留行內的空格，不會將一句話拆成多次輸入。

對每行文字，使用 `for` 迴圈從 `i = 0` 走訪到 `str.size() - 1`，並依照以下順序操作：

1. 使用 `tolower(str[i])` 將目前字元轉成小寫。若不是大寫字母，字元維持原樣。
2. 使用 `mp[tolower(str[i])]` 查詢解碼後的字元。
3. 直接輸出查詢結果，不需要另外建立儲存答案的字串。

每行所有字元處理完後，輸出換行。

## 複雜度

設 `n` 為輸入資料的總字元數（包含換行），`m` 為最長一行文字的長度。

- **時間複雜度：O(n)**。每個字元只需轉換大小寫與查詢一次。雖然 `map` 查詢需要 O(log k)，但對照表的項目數 `k` 有固定上限，因此每次查詢可視為 O(1)。

- **空間複雜度：O(m + 1)**。`str` 儲存一行文字，最多需要 O(m) 空間；鍵盤對照表的大小固定，使用 O(1) 額外空間。

## 備註：

鍵盤位置是按照每一列分別計算，替換成左邊第二個位置的字元，而不是依照英文字母順序往前移動兩個字母。

這題就是單純的手動製表順便檢查鍵盤是否有故障。
