# UVa 11332 - Summing Digits

## 題目連結

- [UVa 11332 - Summing Digits](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&page=show_problem&problem=2307)

## 題意摘要

給定一個正整數 `N`，將它的十進位各位數相加。若加總後仍不是一位數，就繼續對新的數字進行相同操作，直到只剩下一位數為止。

例如 `1234567892` 的各位數加總為 `47`，接著得到 `4 + 7 = 11`，最後得到 `1 + 1 = 2`，所以答案為 `2`。

## 輸入說明

1. 每行輸入一個正整數 `N`，且 `N ≤ 2000000000`。
2. 當輸入為 `0` 時，代表輸入結束，不需要處理或輸出這一行。

## 輸出說明

- 對每筆測資，輸出反覆加總各位數後得到的一位數。
- 每筆答案各占一行。
