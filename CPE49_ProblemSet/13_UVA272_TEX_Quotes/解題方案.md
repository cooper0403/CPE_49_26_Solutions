# 解決方案

因為雙引號只需要依照出現順序交替轉換，所以使用 `bool f` 記錄目前應該輸出哪一種引號。

當 `f` 為 `0` 時，輸出兩個反引號；當 `f` 為 `1` 時，輸出兩個單引號。每處理一個雙引號，就切換一次狀態，其餘字元直接輸出。

## 具體操作：

先設定 `bool f = 0`，再使用 `while(getline(cin, str))` 逐行讀取文字。

使用 `for(auto &it : str)` 走訪每個字元。若 `it` 為雙引號，就依照 `f` 輸出對應的兩個引號，再執行 `f ^= 1` 切換狀態；否則直接輸出 `it`。

每行處理完後換行，並保留 `f` 的狀態繼續讀取下一行，直到 EOF。

## 複雜度

設 `n` 為輸入的總字元數，`m` 為最長一行文字的長度。

- **時間複雜度：O(n)**。每個字元只需要判斷與輸出一次。

- **空間複雜度：O(m + 1)**。使用字串儲存一行文字，`f` 只需要 O(1) 額外空間。

## 備註：

`f ^= 1` 可以讓狀態在 `0` 與 `1` 之間切換。

一對引號可能跨行，因此 `f` 應在讀取迴圈外初始化，不能每讀取一行就重設。

只需要替換雙引號，原本的單引號與反引號直接保留。
