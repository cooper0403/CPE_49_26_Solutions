# UVa 272 - TEX Quotes

## 題目連結

- [UVa 272 - TEX Quotes](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&category=4&page=show_problem&problem=208)

## 題意摘要

給定多行文字，將一般雙引號轉換成 TEX 使用的引號格式。

遇到的第一個雙引號替換成兩個反引號，第二個替換成兩個單引號，後續依此交替處理，其餘文字保持原樣。

## 輸入說明

1. 輸入包含多行文字，整份輸入的雙引號總數為偶數。
2. 一對引號可能分布在不同行，不涉及巢狀引號。
3. 持續讀取直到檔案結束（EOF）。

## 輸出說明

- 依據整份的輸入順序，奇數引號改成兩個反引號，偶數引號改成兩個單引號。
- 其餘字元、空格與換行維持原樣。
