# UVa 10783 - Odd Sum

## 題目連結

- [UVa 10783 - Odd Sum](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&category=19&page=show_problem&problem=1724)

## 題意摘要

給定整數區間 `[a, b]`，求區間內所有奇數的總和，包含兩端點。

例如 `[3, 9]` 中的奇數為 `3、5、7、9`，總和為 `24`。

## 輸入說明

1. 第一行輸入測資筆數 `T`，且 `1 ≤ T ≤ 100`。
2. 每筆測資包含兩個整數 `a` 與 `b`，各占一行。
3. `0 ≤ a ≤ b ≤ 100`。

## 輸出說明

- 每筆測資輸出一行，格式為 `Case k: ans`。
- `k` 為從 `1` 開始的測資編號，`ans` 為區間內所有奇數的總和。
