# 解決方案

因為只需要加總區間內的奇數，所以先將起點調整為第一個符合範圍的奇數，再每次增加 `2`，依序累加即可。

使用 `a |= 1` 將最低位元設為 `1`。若 `a` 原本是偶數，就會增加 `1`；若原本是奇數，則保持不變。

## 具體操作：

先使用 `cin >> t` 讀取測資筆數，再透過 `for(int i = 1; i <= t; i++)` 處理各筆測資，並以 `i` 作為輸出編號。

讀取 `a` 與 `b`，設定 `ans = 0`，再執行 `a |= 1`，讓 `a` 成為不小於原本起點的第一個奇數。

使用 `while(a <= b)` 執行 `ans += a`，再透過 `a += 2` 移到下一個奇數，直到超過上界。

最後依照 `Case i: ans` 的格式輸出，並換行。

## 複雜度

設 `n` 為原本區間內的整數個數，以下以單筆測資計算。

- **時間複雜度：O(n)**。每次跳過偶數，處理的奇數數量約為區間長度的一半。

- **空間複雜度：O(1)**。只使用固定數量的變數進行計算。

## 備註：

`a |= 1` 是位元 OR 的複合指定運算，不是每次都將 `a` 加一；已經是奇數時，數值不會改變。

若區間沒有奇數，調整後的起點會大於 `b`，迴圈不會執行，答案保持為 `0`。

存在一種數學公式解(時間為O(1))但是範圍過小沒有必要使用。
