# UVa 11349 - Symmetric Matrix

## 題目連結

- [UVa 11349 - Symmetric Matrix](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&category=24&page=show_problem&problem=2324)

## 題意摘要

給定一個 `n × n` 的方陣，判斷所有元素是否皆為非負數，且以矩陣中心對稱，也就是旋轉 180 度後仍與原本的矩陣相同。

若將矩陣依照每列由左到右、由上到下的順序排成一列，第一個元素必須等於最後一個，第二個必須等於倒數第二個，依此類推。

## 輸入說明

1. 第一行輸入測資筆數 `T`，且 `T ≤ 300`。
2. 每筆測資先輸入 `N = n`，其中 `n` 為矩陣的邊長，且 `1 ≤ n ≤ 100`。
3. 接下來輸入 `n` 列，每列包含 `n` 個整數，代表矩陣的各個元素。
4. 元素範圍為 `-2^32 ≤ M[i][j] ≤ 2^32`；注意到`可能超出普通int的範圍`。

## 輸出說明

- 每筆測資輸出一行，編號從 `1` 開始，第二筆則輸出`2`以此類推 。
- 若所有元素皆為非負數，且以中心對稱，輸出 `Test #k: Symmetric.`。
- 否則輸出 `Test #k: Non-symmetric.`。
- `k` 為測資編號，注意冒號後的空格，以及輸出結尾的句點。
- 輸出範例：`Test #1: Symmetric.`
