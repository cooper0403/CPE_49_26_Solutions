# 解決方案

將矩陣依輸入順序看成一陣列。如果矩陣以中心對稱，前後相對位置的數值就會相同，因此只需要儲存前半部，再反向比對後半部即可。

除此之外此題還要求全部皆為非負數，才能在對稱的情況下輸出 `Symmetric.`。

## 具體操作：

先輸入總測資數 t ，然後讀取每筆測的第一行運用技巧 string 來把前面兩個字元外加無意義的空白跳過，使其結構變為" 數字"的形式，然後輸入方陣的一行的大小。

以下以 `N` 表示剛讀入的矩陣邊長（程式中的變數 `n`），並以 `n = N × N` 表示矩陣的元素總數。後續的 `n / 2` 與複雜度都以元素總數計算。

接下來建立一個大小為 n/2若為奇數在+1的陣列，將前半段(包含奇數時的n/2+1)輸入時檢查是否存在負數若存在則做標記並繼續輸入。

然後運用技巧在輸入時檢查陣列對應的位置是否相同，於我的代碼中使用的是xor作為檢查方式，熟悉位運算的因該都可以知道原理。

在過程中若有發現負數或是對應位置不相等的情況下，標記會發生一次改變使其輸出的是 `Non-symmetric.`，而非 `Symmetric.`。

## 複雜度

設 `n` 為矩陣中元素的數量，以下以單筆測資計算。

- **時間複雜度：O(n)**。全部 `n` 個元素都只讀取一次，檢查負數與比對對應位置都只需要固定時間。

- **空間複雜度：O(n)**。使用 `vector` 儲存前半部，元素數量為 `⌈n / 2⌉`。

## 備註：

當 `n` 為奇數時，中心元素會存入前半部，但不需要與後半部重複比對。中心元素也必須是非負數。

即使已經判斷不符合條件，也要繼續讀完整個矩陣，避免影響下一筆測資的輸入位置。
