# UVa 10019 - Funny Encryption Method

## 題目連結

- [UVa 10019 - Funny Encryption Method](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&category=24&page=show_problem&problem=960)

## 題意摘要

給定一串數字，先將它視為十進位整數，計算其二進位表示中 `1` 的個數 `b1`；再將同一串數字視為十六進位整數，計算其二進位表示中 `1` 的個數 `b2`。

例如輸入 `265`，十進位的 `265` 對應 `b1 = 3`；十六進位的 `265` 對應 `b2 = 5`。

## 輸入說明

1. 第一行輸入測資筆數 `N`，且 `1 ≤ N ≤ 1000`。
2. 接下來每筆測資輸入一個十進位正整數 `M`，且 `1 ≤ M ≤ 9999`。

## 輸出說明

- 每筆測資依序輸出 `b1 b2`，中間以一個空格分隔，各占一行。
