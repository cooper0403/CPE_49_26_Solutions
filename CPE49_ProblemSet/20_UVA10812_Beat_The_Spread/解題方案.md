# 解決方案

設較大的分數為 `a`、較小的分數為 `b`，則有 `a + b = sum`、`a - b = d`。

因此較小的分數為 `(sum - d) / 2`，較大的分數再加上 `d` 即可。若分差大於總分，或 `sum - d` 不是偶數，就無法得到合法的非負整數分數。

## 具體操作：

先使用 `cin >> t` 讀取測資筆數，再透過 `while(cin >> sum >> d)` 持續讀取每筆的總分與分差。

若 `d > sum`，或 `(sum - d) / 2 + d + (sum - d) / 2 != sum`(這個是判斷a+b是否可以等於初始的sum)，就輸出 `impossible`。

第二個條件是將計算出的兩個分數加回去，檢查是否等於原本的總分。因為整數除法會捨去小數部分，當 `sum - d` 為奇數時，加回去就會比總分少 `1`。

否則，先輸出 `(sum - d) / 2 + d`，再輸出 `(sum - d) / 2`，中間加上一個空格，最後換行。

## 複雜度

以下以單筆測資計算。

- **時間複雜度：O(1)**。只需要固定次數的比較與算術運算，處理全部 `t` 筆測資需要 O(t)。

- **空間複雜度：O(1)**。只使用固定數量的變數進行計算。

## 備註：

分數可以是 `0`，也可以相同；當分差為 `0` 時，兩隊分數相等。

程式雖然讀取測資筆數 `t`，但實際使用 EOF 控制後續輸入。
