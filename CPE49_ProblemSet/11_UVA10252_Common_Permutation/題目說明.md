# UVa 10252 - Common Permutation

## 題目連結

- [UVa 10252 - Common Permutation](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&page=show_problem&problem=1193)

## 題意摘要

給定兩個由小寫英文字母組成的字串 `a` 與 `b`，找出兩者共有的字母，組成最長的字串，並按字母順序輸出。

同一個字母可以重複出現，但次數不能超過它在任一輸入字串中的出現次數。例如 `aab` 與 `abb` 的答案為 `ab`。

## 輸入說明

1. 每兩行為一組測資，第一行為字串 `a`，第二行為字串 `b`。
2. 每個字串最多包含 1000 個小寫英文字母。
3. 持續讀取直到檔案結束（EOF）。

## 輸出說明

- 每組測資輸出一行，包含兩個字串共有的字母，依 `a` 到 `z` 排列。
- 每個字母輸出的次數，為它在兩個字串中出現次數的較小值。
- 若沒有共同字母，輸出空行。
