# 解決方案

先將PI存於double中使用 asin(1)*2.0來實現

然後將地球半徑 `6440` 加上衛星高度，得到軌道半徑 `r`。把圓心角換成較小的角，再轉為弧度 `θ`，即可計算弧長 `r * θ` 與弦長 `2r * sin(θ / 2)`。

## 具體操作：

1. 使用 `while(cin >> a >> b >> str)` 讀取資料。若單位為 `min`，執行 `b /= 60.0` 將角分換成度。
2. 執行 `a += 6440.0` 得到軌道半徑。若 `b > 180.0`，就用 `360.0 - b` 取得較小的圓心角。
3. 使用 `b * PI / 180.0` 將角度換成弧度，再依序輸出 `a * b` 與 `2.0 * a * sin(b / 2.0)`，皆保留六位小數。

## 複雜度

- **時間複雜度：O(1)**。每筆測資只需固定次數的換算與三角函數運算。
- **空間複雜度：O(1)**。只儲存當前測資與角度單位。

## 備註：

θ為theta。

弦長公式可將兩條半徑形成的等腰三角形切成兩個直角三角形來推導，其中半弦長為 `r × sin(θ / 2)`。
