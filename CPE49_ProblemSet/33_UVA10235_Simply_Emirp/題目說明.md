# UVa 10235 - Simply Emirp

## 題目連結

- [UVa 10235 - Simply Emirp](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&category=24&page=show_problem&problem=1176)

## 題意摘要

對每個整數 `N`，先判斷它是不是質數。如果是質數，且十進位數字反轉後得到另一個不同的質數，則稱它為 emirp。

例如 `17` 和反轉後的 `71` 都是質數，因此 `17` 是 emirp；`11` 反轉後仍是自己，只算質數。

## 輸入說明

1. 每行輸入一個整數 `N`，其中 `1 < N < 1000000`。
2. 讀取直到檔案結尾（EOF）。

## 輸出說明

- 若 `N` 不是質數，輸出 `N is not prime.`。
- 若 `N` 是質數但不是 emirp，輸出 `N is prime.`。
- 若 `N` 是 emirp，輸出 `N is emirp.`。
- 每筆測資輸出一行。
