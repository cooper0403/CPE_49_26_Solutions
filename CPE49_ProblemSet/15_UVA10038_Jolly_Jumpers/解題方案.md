# 解決方案

長度為 `n` 的序列共有 `n - 1` 個相鄰差，因此只要每個差的絕對值都介於 `1` 到 `n - 1`，且沒有重複，就能確定所有需要的差值都已出現。

使用 `vector<int>` 記錄序列，再用另一個陣列標記已出現的差值。讀取數字時就能同時完成檢查。

## 具體操作：

使用 `while(cin >> t)` 讀取每筆序列的長度，建立 `vec(t)` 儲存數字、`chack(t - 1)` 標記差值，並設定 `bool ans = 1`。

依序讀取 `vec[i]`，從第二個數字開始，計算 `temp = abs(vec[i] - vec[i - 1]) - 1`，將差值轉成從 `0` 開始的索引。

若 `temp >= 0`、`temp < t - 1`，且 `chack[temp] == 0`，就將該位置設為 `1`；否則代表差值超出範圍或已經出現，將 `ans` 設為 `0`。

全部數字讀取完成後，若 `ans` 為 `1` 就輸出 `Jolly`，否則輸出 `Not jolly`，最後換行。

## 複雜度

設 `n` 為單筆序列的長度。

- **時間複雜度：O(n)**。初始化陣列與讀取、檢查序列都只需要線性時間。

- **空間複雜度：O(n)**。使用 `vec` 儲存序列，並以 `chack` 記錄差值是否出現。

## 備註：

差值減一是為了讓 `1` 到 `n - 1` 對應到索引 `0` 到 `n - 2`。

因為剛好有 `n - 1` 個相鄰差，只要都在合法範圍且不重複，就不需要另外掃描陣列檢查是否有缺漏。

當 `n = 1` 時，不會進入相鄰差的檢查，`ans` 保持為 `1`，因此會輸出 `Jolly`。
