# UVa 10038 - Jolly Jumpers

## 題目連結

- [UVa 10038 - Jolly Jumpers](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&category=12&page=show_problem&problem=979)

## 題意摘要

給定一個長度為 `n` 的整數序列，若相鄰元素差的絕對值恰好**包含** `1` 到 `n - 1`，則稱為 Jolly Jumper。

例如 `1 4 2 3` 的相鄰差絕對值為 `3、2、1`，因此是 Jolly Jumper。只有一個元素的序列也符合條件。

## 輸入說明

1. 每行輸入一個整數 `n`，後面接著 `n` 個整數，代表序列內容。
2. `1 ≤ n ≤ 3000`，序列中的數字可以是負數。
3. 持續讀取直到檔案結束（EOF）。

## 輸出說明

- 若序列符合條件，輸出 `Jolly`。
- 否則輸出 `Not jolly`。
- 每筆答案各占一行。
