# 解決方案

設玩家人數為 `A`、單次成功機率為 `C`、指定玩家編號為 `B`，並令 `q = 1 - C`，代表單次失敗機率。

指定玩家在第一輪獲勝，需要前面 `B - 1` 位玩家失敗，再由自己成功，所以機率為 `q^(B - 1) * C`。

若整輪所有玩家都失敗，就會重新開始，每多一輪完整的失敗，機率便再乘上 `q^A`。將所有輪次的獲勝機率以無窮等比級數加總，可得 `q^(B - 1) * C / (1 - q^A)`。

## 具體操作：

先使用 `getline(cin, T)` 讀取第一行測資筆數，再使用 `while(cin >> A >> C >> B)` 持續讀取每筆資料，直到 EOF。

若 `C != 0.0`，先計算 `q = 1.0 - C`，再使用 `pow` 套入公式：`ans = (pow(q, B - 1) * C) / (1 - pow(q, A))`。

透過 `fixed << setprecision(4)` 固定輸出小數點後四位，再換行。若 `C == 0.0`，則直接輸出 `0.0000`。

## 複雜度

以下以單筆測資計算，並將題目範圍內的 `pow` 運算視為固定時間。

- **時間複雜度：O(1)**。只需要固定次數的算術與次方運算，處理全部 `S` 筆測資需要 O(S)。

- **空間複雜度：O(1)**。只使用固定數量的變數儲存輸入與計算結果。

## 備註：

當成功機率為 `0` 時，沒有人能獲勝，而且公式的分母會變成 `0`，因此需要另外處理。

`q` 是單次失敗機率，`q^A` 則是一整輪所有玩家都失敗的機率。

程式只讀取並略過第一行的測資筆數，實際使用 EOF 控制後續輸入。

實際上使用cin >> t(int) 然後while(t--)是更標準的解法。

此題使用EOF控制是為了展示judge接受使用EOF控制作為終止條件的代碼。

關於公式的部分，建議直接背因為臨時推導難度過高。
