# UVa 10056 - What is the Probability?

## 題目連結

- [UVa 10056 - What is the Probability?](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&category=12&page=show_problem&problem=997)

## 題意摘要

有 `N` 位玩家依編號順序輪流進行遊戲，每次成功的機率皆為 `p`。若有人成功，遊戲立即結束；若所有人都失敗，就從第一位玩家繼續。

給定玩家編號 `I`，求該玩家最終獲勝的機率。

## 輸入說明

1. 第一行輸入測資筆數 `S`，且 `S ≤ 1000`。
2. 每筆測資輸入 `N p I`，分別代表玩家人數、單次成功機率與欲查詢的玩家編號。
3. `1 ≤ N ≤ 1000`、`0 ≤ p ≤ 1`，且 `1 ≤ I ≤ N`。

## 輸出說明

- 每筆測資輸出指定玩家最終獲勝的機率，各占一行。
- 答案固定輸出小數點後四位。
