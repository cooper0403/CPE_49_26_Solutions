# UVa 11417 - GCD

## 題目連結

- [UVa 11417 - GCD](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&category=24&page=show_problem&problem=2412)

## 題意摘要

給定整數 `N`，枚舉所有符合 `1 ≤ i < j ≤ N` 的配對，將每一對的最大公因數 `gcd(i, j)` 加總。

## 輸入說明

1. 每行輸入一個整數 `N`，且 `1 < N < 501`。
2. 輸入最多 100 行。讀到 `0` 時結束，不處理這一行。

## 輸出說明

- 每筆測資輸出一行，內容為所有指定配對的最大公因數總和。
