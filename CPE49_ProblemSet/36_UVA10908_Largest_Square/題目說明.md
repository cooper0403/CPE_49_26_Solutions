# UVa 10908 - Largest Square

## 題目連結

- [UVa 10908 - Largest Square](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&category=24&page=show_problem&problem=1849)

## 題意摘要

給定一個 `M × N` 的字元矩陣。每次指定中心 `(r, c)`，找出以該格為中心、完全位於矩陣內，且所有格子字元相同的最大正方形，輸出它的邊長。

最小可行的正方形是中心格本身，邊長為 `1`。往外擴一圈後，邊長增加 `2`。

## 輸入說明

1. 第一行輸入測資組數 `T`，且 `T < 21`。
2. 每組先輸入列數 `M`、欄數 `N` 及查詢數 `Q`。其中 `M`、`N` 最多為 `100`，且 `Q < 21`。
3. 接著是 `M` 行，每行有 `N` 個字元。
4. 最後輸入 `Q` 組中心座標 `r c`。座標從 `0` 開始，左上角為 `(0, 0)`。

## 輸出說明

- 每組測資先輸出 `M N Q`，以一個空格分隔。
- 接下來的 `Q` 行依序輸出各查詢的最大正方形邊長。
