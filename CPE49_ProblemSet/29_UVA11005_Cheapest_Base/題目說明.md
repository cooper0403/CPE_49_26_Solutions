# UVa 11005 - Cheapest Base

## 題目連結

- [UVa 11005 - Cheapest Base](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&category=24&page=show_problem&problem=1946)

## 題意摘要

給定 `0`～`9` 與 `A`～`Z` 各自的印刷成本。對每個十進位整數，找出在 `2`～`36` 進位中，印出該數字所需成本最低的所有進位。

一種進位的總成本，是該進位表示中每個字元的成本相加。同一個字元若出現多次，就要計入多次。數字不補前導零；數字 `0` 本身仍需要印出一個 `0`。

## 輸入說明

1. 第一行輸入測資組數 `T`，且 `T < 25`。
2. 每組測資先輸入 4 行，每行 9 個整數，依序代表 `0`～`9`、`A`～`Z` 的 36 個成本，每個成本介於 `1` 與 `128`。
3. 接著輸入查詢數量，再逐行輸入要查詢的十進位整數 `x`，其中 `0 ≤ x ≤ 2000000000`。

## 輸出說明

- 每組測資先輸出 `Case k:`，其中 `k` 從 `1` 開始。
- 每筆查詢輸出 `Cheapest base(s) for number x:`，接著以一個空格分隔各個最低成本的進位，按進位由小到大列出。
- 兩組測資之間留一個空白行。
