# UVa 100 — The 3n + 1 problem

## 題目連結

- [UVa 100 — The 3n + 1 problem](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&page=show_problem&problem=36)

## 題意摘要

給定一個正整數 `n`，依照以下規則產生數列，直到 `n` 變成 1：

- 當 `n` 為奇數時，將 `n` 改為 `3n + 1`。
- 當 `n` 為偶數時，將 `n` 改為 `n / 2`。

從起始數字到最後的 1，數列中出現的數字總數稱為「循環長度」，起始數字與最後的 1 都要計入。

這題會給定兩個整數 `i` 與 `j`，需要找出兩者之間所有整數的最大循環長度，範圍包含 `i` 與 `j`。

## 輸入說明

每筆測資有一行，包含兩個正整數 `i` 與 `j`，符合 `0 < i, j < 10000`。

`i` 與 `j` 的大小順序不一定，輸入直到 EOF 結束。

## 輸出說明

每筆測資輸出一行，依序輸出原本的 `i`、`j`，以及兩者之間所有整數的最大循環長度，三個數字以空白分隔。

注意輸出的 `i` 與 `j` 必須保留原本的輸入順序，即使 `i` 大於 `j`，也不能交換輸出順序。
