# UVa 10035 — Primary Arithmetic

## 題目連結

- [UVa 10035 — Primary Arithmetic](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&page=show_problem&problem=976)

## 題意摘要

將兩個十進位整數相加時，需要從個位數開始，由右到左逐位計算。如果某一位的總和大於或等於 10，就會向下一位進位。

這題需要計算兩個整數相加的過程中，總共發生幾次進位，不需要輸出相加後的結果。

## 輸入說明

每筆測資有一行，包含兩個非負整數，每個整數的位數少於 10。

當輸入為 `0 0` 時結束，這一筆不需要處理或輸出。

## 輸出說明

每筆測資輸出一行，依進位次數使用以下格式：

- 沒有進位：`No carry operation.`
- 進位一次：`1 carry operation.`
- 進位多次：`n carry operations.`，其中 `n` 為進位次數。

注意複數時需要加 `s`，以及輸出結尾的句點。
