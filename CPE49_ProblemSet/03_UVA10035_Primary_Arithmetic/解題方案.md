# 解決方案

使用字串讀取兩個整數，從最右邊的個位數開始模擬直式加法，計算每一位是否產生進位。

每一位的總和包含兩個數字在該位的值，以及前一位留下的進位。如果總和大於或等於 10，進位次數加一，並將進位值設為 1；否則將進位值設為 0。

## 具體步驟

將兩個數當作字串處理，然後從右向左同時移動，配合 `carr` 來記錄是否有進位（初始設為 0）。

在移動索引位置時，要注意是否為合法的索引位置。

計算有多少進位次數，然後，輸出時注意那三種狀態。

當兩個字串都只有 `"0"` 時，即終止。

## 複雜度

設 `n` 為兩個輸入整數中較大的位數。

- **時間複雜度：O(n)**。讀取字串與逐位計算最多處理 O(n) 個字元，每一位的計算時間為 O(1)。
- **空間複雜度：O(n)**。使用兩個字串儲存輸入數字；兩者的總長度最多為 `2n`。

## 注意事項

- 終止條件是兩個數字同時為 `0`。只有其中一個為 `0` 時，仍需要處理。
- 兩個數字的位數可能不同，存取字元前要確認索引仍在範圍內。
- 前一位的進位要加入下一位的計算，連續進位也要逐次計數。
- 最高位產生的進位，已在處理最高位時算入一次，不需要再因最後剩下的進位值額外加一次。
- `sum / 10` 可判斷是否進位：每位總和最多為 19，因此結果只會是 0 或 1。
- 沒有進位與一次進位時使用單數 `operation`，多次進位時使用複數 `operations`。
