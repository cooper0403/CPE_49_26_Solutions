# 解決方案

先建立費波那契數列，再由大到小檢查。若目前的數字不大於剩餘值，就選取並扣除它，輸出 `1`；否則在答案開始後輸出 `0`。

每次優先選取不超過剩餘值的最大費波那契數，就能得到題目要求的表示法。

## 具體操作：

建立 `vector<long long> vec(2, 1)`，以兩個 `1` 開始，持續加入前兩項的和，直到最後一項不小於 `100000001`，涵蓋所有可能的輸入。

先使用 `cin >> n` 讀取測資筆數，再使用 `while(cin >> n)` 讀取每個數字。扣除前先輸出原本的 `n` 與 ` = `。

從 `vec` 的最後一項往前走訪到索引 `1`，並設定 `f = 0` 記錄是否已開始輸出。

若 `n >= vec[i]`，就執行 `n -= vec[i]`、輸出 `1`，並將 `f` 設為 `1`；否則只有在 `f` 已為 `1` 時才輸出 `0`。

全部處理完後輸出 ` (fib)` 並換行。

## 複雜度

設 `k` 為預先建立的費波那契數列長度。

- **時間複雜度：O(k)**。建表只需執行一次，每筆測資也只需由大到小走訪一次數列。

- **空間複雜度：O(k)**。所有測資共用同一個數列，每筆計算只使用 O(1) 額外空間。

## 備註：

數列開頭有兩個 `1`，但表示法只使用其中一個，因此走訪到索引 `1` 就停止，不處理索引 `0`。

`f` 用來避免輸出前導零；第一個 `1` 輸出後，其餘未選取的位置都需要輸出 `0`。

程式雖然讀取測資筆數，但實際使用 EOF 控制後續輸入。
