# UVa 948 - Fibonaccimal Base

## 題目連結

- [UVa 948 - Fibonaccimal Base](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&category=24&page=show_problem&problem=889)

## 題意摘要

將十進位正整數轉換成費波那契表示法。每個位數由右到左分別對應 `1、2、3、5、8、13……`，使用該數字就寫 `1`，沒有使用就寫 `0`。

同一個費波那契數只能使用一次，而且不能同時使用數列中相鄰的兩個數，因此答案不會出現連續的 `1`，也不能有前導零。

例如 `17 = 13 + 3 + 1`，表示為 `100101`。

## 輸入說明

1. 第一行輸入測資筆數 `N`，且 `1 ≤ N ≤ 500`。
2. 接下來 `N` 行，每行輸入一個小於 `100000000` 的正整數。

## 輸出說明

- 每筆測資輸出一行，格式為 `原本的數字 = 費波那契表示法 (fib)`。
- 例如 `17 = 100101 (fib)`，注意等號兩側與 `(fib)` 前的空格。
