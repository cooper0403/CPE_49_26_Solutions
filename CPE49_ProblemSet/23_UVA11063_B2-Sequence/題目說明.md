# UVa 11063 - B2-Sequence

## 題目連結

- [UVa 11063 - B2-Sequence](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&category=16&page=show_problem&problem=2004)

## 題意摘要

給定一個長度為 `n` 的整數數列，判斷是否為 B2-Sequence，必須同時符合以下條件：

1. 所有元素皆為正整數，且數列嚴格遞增，也就是 `1 ≤ b[1] < b[2] < ... < b[n]`。
2. 所有 `b[i] + b[j]` 的結果都不能重複，其中 `1 ≤ i ≤ j ≤ n`，包含同一個元素與自己相加的情況。

例如數列 `1 2 3` 雖然是正整數且嚴格遞增，但因為 `1 + 3 = 2 + 2`，所以不是 B2-Sequence。

## 輸入說明

1. 每筆測資先輸入數列長度 `n`，且 `2 ≤ n ≤ 100`。
2. 接著輸入 `n` 個整數，代表數列中的各個元素，每個元素皆不超過 `10000`。
3. 是否符合正整數與嚴格遞增的條件，需要另外判斷，不能直接假設輸入已符合。
4. 每筆測資後有一個空白行，沒有另外提供測資筆數，讀取直到檔案結尾（EOF）為止。

## 輸出說明

- 若符合條件，輸出 `Case #k: It is a B2-Sequence.`。
- 若不符合條件，輸出 `Case #k: It is not a B2-Sequence.`。
- `k` 為測資編號，從 `1` 開始，注意冒號後的空格與結尾的句點。
- 每筆測資輸出後，必須再輸出一個空白行。
- 所以每筆輸出總共會包含兩個換行符號。
