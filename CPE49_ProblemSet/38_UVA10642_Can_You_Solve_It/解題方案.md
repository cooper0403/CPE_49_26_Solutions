# 解決方案

設 `s = x + y`。第 `s` 條對角線之前的各條對角線依序有 `1、2、…、s` 個點，因此前面共有 `s * (s + 1) / 2` 個點。

同一條對角線從 `(0, s)` 開始，走到 `(x, y)` 需要再走 `x` 步。以 `(0, 0)` 的編號為 `0`，點的編號就是 `s * (s + 1) / 2 + x`，兩點間的步數等於終點編號減去起點編號。

## 具體操作：

1. 讀入四個座標值，計算起點與終點的座標和 `xy1`、`xy2`。
2. 對任一座標和 `s`，程式使用 `(s >> 1) * s + (s & 1) * (s >> 1) + ((s + 1) >> 1)` 算出前面各條對角線的點數。`s >> 1` 取得整數除以二的商，`s & 1` 區分奇偶；合起來等價於 `s * (s + 1) / 2`。
3. 將兩個點的結果分別加上各自的 `x`，得到起點編號 `b` 與終點編號 `e`，再依 `Case k: steps` 格式輸出 `e - b`。

## 複雜度

- **時間複雜度：O(1)**。每筆測資只需計算兩個點的編號。
- **空間複雜度：O(1)**。只儲存四個座標值與固定數量的變數。

## 備註：

座標和最大可達 `200000`，點的編號可能超過 32 位元 `int` 的範圍。
