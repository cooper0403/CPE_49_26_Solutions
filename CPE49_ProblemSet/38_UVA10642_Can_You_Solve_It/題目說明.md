# UVa 10642 - Can You Solve It?

## 題目連結

- [UVa 10642 - Can You Solve It?](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&page=show_problem&problem=1583)

## 題意摘要

從 `(0, 0)` 開始，依 `x + y` 由小到大走過各條對角線。同一條對角線內，依 `x` 由小到大前進。例如路徑開頭為 `(0, 0) → (0, 1) → (1, 0) → (0, 2) → (1, 1) → (2, 0)`。

給定起點與終點，求沿箭頭從起點走到終點需要幾步。每經過一條箭頭算一步，題目保證終點可達。

## 輸入說明

1. 第一行輸入測資筆數 `n`，且 `1 ≤ n ≤ 500`。
2. 接下來每行輸入 `x1 y1 x2 y2`，依序為起點與終點座標。各座標值皆為 `0` 到 `100000` 的整數。

## 輸出說明

- 每筆測資輸出一行，格式為 `Case k: steps`。
- `k` 為從 `1` 開始的測資編號，`steps` 為起點到終點的步數。
