# UVa 10093 - An Easy Problem!

## 題目連結

- [UVa 10093 - An Easy Problem!](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&category=16&page=show_problem&problem=1034)

## 題意摘要

給定一個`N`為基數(Base)的整數`R`，且已知`R`能被`N - 1` 整除，你需要求`N`的最小可能的值，`N`的值所在的範圍為`2 ≤ N ≤ 62`，若`N`不在其中請輸出`such number is impossible!`。

## 輸入說明

1. 每行輸入一個`2`到`62`為基數(Base)的整數(根據數學定義)。
2. 大小寫字母代表不同的數值，例如 `A` 為 `10`，`a` 為 `36`。
3. 持續讀取直到檔案結束（EOF）。

## 輸出說明

- 若存在符合條件的進位制，輸出最小的 `N`，以十進位表示。
- 若不存在，輸出 `such number is impossible!`。
- 每筆答案各占一行。
