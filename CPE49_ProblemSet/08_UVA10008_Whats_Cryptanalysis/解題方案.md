# 解決方案

因為題目需要統計所有英文字母的出現次數，且大小寫視為相同，所以先將字母轉成大寫，再使用大小為 26 的 `vector<int>` 紀錄各字母的數量。

輸入可能包含空白與空行，所以使用 `getline` 逐行讀取，並略過非英文字母的字元。

題目要求依出現次數由多到少輸出，若次數相同則按字母順序輸出。可以使用 `map<int, string>`，將次數乘上 `-1` 作為 key，並將相同次數的字母依序加入同一個字串。

因為 `map` 預設會將 key 由小到大排列，負值越小代表原本的次數越多，因此走訪 `map` 就能實現次數由多到少的輸出順序。

## 具體操作：

先使用 `cin >> t` 讀取接下來的行數，再呼叫一次 `getline(cin, line)` 讀取整數後剩下的內容與換行，讓後續讀取從第一行文字開始。

建立 `vector<int> cont(26)`，其中每個元素的初始值都是 `0`，索引 `0` 到 `25` 分別代表 `A` 到 `Z`。

使用 `while(t--)` 逐行讀取文字，並依照以下順序操作：

1. 使用 `getline(cin, line)` 讀取完整一行，保留行內的空白。
2. 使用 `for(auto &it : line)` 走訪每個字元，並用 `isalpha(it)` 判斷是否為字母。
3. 若為字母，使用 `toupper(it)` 將其轉成大寫，再執行 `cont[it - 'A']++`，累加該字母的出現次數。

統計完成後，建立 `map<int, string> mp`，並以 `i = 0` 到 `25` 的順序檢查每個字母：

1. 使用 `char ch = 'A' + i` 取得對應的大寫字母。
2. 若 `cont[i]` 不為 `0`，執行 `mp[cont[i] * -1].push_back(ch)`，將字母加入對應次數的字串中。
3. 因為加入字母的順序是 `A` 到 `Z`，所以同一次數的字串已經按字母順序排列，不需要另外排序。

最後使用 `for(auto &it : mp)` 走訪所有項目，再逐一輸出 `it.second` 中的字母。每行輸出一個大寫字母、一個空格與 `it.first * -1`，將負值還原成實際出現次數，最後換行。

## 複雜度

- **時間複雜度：O(n)**。每個輸入字元只需讀取與判斷一次；後續最多處理 26 個字母，`map` 的建立與走訪有固定上限。

- **空間複雜度：O(m + 1)**。`line` 儲存一行文字，最多需要 O(m) 空間；`cont` 與 `map` 最多儲存 26 個字母的資料，使用固定上限的額外空間。
