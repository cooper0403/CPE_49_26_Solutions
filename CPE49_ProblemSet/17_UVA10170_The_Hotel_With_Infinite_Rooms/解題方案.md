# 解決方案

因為每個團體的人數就是住宿天數，所以可以從指定天數中依序扣除各團體的住宿天數，直接模擬入住過程。

使用 `m` 記錄目前團體的人數，`d` 記錄剩下需要計算的天數。每次執行 `d -= m`，再將 `m` 加一；當 `d <= 0` 時，就代表指定日期落在剛剛扣除的團體住宿期間。

## 具體操作：

使用 `long long m, d` 儲存資料，再透過 `while(cin >> m >> d)` 讀取每筆測資。

使用 `while(d > 0)` 持續執行 `d -= m`，扣除目前團體的住宿天數，再執行 `m++`，移到下一個團體。

迴圈結束時，`m` 已經比答案多一人，因此輸出 `m - 1` 並換行。

## 複雜度

設 `n` 為原本欲查詢的天數，以下以單筆測資計算。

- **時間複雜度：O(√n)**。每次扣除的天數逐漸增加，前 `k` 個團體的累計住宿天數至少為 `k(k + 1) / 2`，因此最壞情況只需處理 O(√n) 個團體。

- **空間複雜度：O(1)**。只使用固定數量的變數進行模擬。

## 備註：

天數可能接近 `10^15`，需要使用 `long long`，不能使用一般的 `int` 儲存。

若扣除後 `d == 0`，代表指定日期恰好是該團體住宿的最後一天，答案仍然是這個團體的人數。

每次扣除後都會執行 `m++`，因此不論最後 `d` 等於 `0` 或小於 `0`，都需要輸出 `m - 1`。

展示的代碼採用模擬法，若追求更低的時間複雜度也可以利用等差級數公式求解。
