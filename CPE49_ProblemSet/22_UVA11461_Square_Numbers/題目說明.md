# UVa 11461 - Square Numbers

## 題目連結

- [UVa 11461 - Square Numbers](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&category=24&page=show_problem&problem=2456)

## 題意摘要

給定兩個正整數 `a` 與 `b`，統計區間 `[a, b]` 內有多少個完全平方數，包含兩個端點。

完全平方數是可以表示成某個整數平方的數，例如 `1`、`4`、`9`。

## 輸入說明

1. 每行輸入兩個整數 `a` 與 `b`，且 `0 < a ≤ b ≤ 100000`。
2. 輸入最多包含 `201` 行，沒有另外提供測資筆數。
3. 當輸入為 `0 0` 時結束，這一行不需要處理，也不需要輸出。

## 輸出說明

- 每筆測資輸出一行，內容為區間 `[a, b]` 內完全平方數的數量。
- 若 `a` 或 `b` 本身是完全平方數，也必須計入。
- 只輸出數量，不需要加上測資編號或其他文字。
- 例如輸入 `1 4` 時，區間內有 `1` 與 `4`，因此輸出 `2`。
