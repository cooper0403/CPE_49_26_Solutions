# 解決方案

多項式的每一項微分後，係數會乘上原本的次方，次方則減一，常數項微分後為 `0`。

將微分後的係數由高次到低次處理，每次先將目前答案乘上 `x`，再加上下一個係數，就能使用 Horner 法計算，不需要逐項求次方。

## 具體操作：

使用 `getline(cin, str)` 讀取第一行，再用 `stoi(str)` 取得 `x`。接著讀取第二行，透過 `stringstream` 拆出各個係數，存入 `vector<ll> vec`。

呼叫 `sol(x, vec)`，先設定 `ans = 0`、`n = vec.size()`。

使用迴圈走訪除了最後一個常數項以外的所有係數。每次先執行 `n--`，讓 `n` 對應目前係數原本的次方，再執行 `ans = ans * x + n * vec[i]`。

全部處理完後，輸出 `ans` 並換行，再繼續讀取下一組資料，直到 EOF。

## 複雜度

設 `n` 為單筆多項式的係數個數。

- **時間複雜度：O(n)**。讀取係數與計算導數值都只需要線性時間。

- **空間複雜度：O(n)**。使用字串與 `vector` 儲存係數資料，其餘計算只需要固定數量的變數。

## 備註：

最後一個係數是常數項，微分後為 `0`，因此迴圈只處理到倒數第二個係數。

若多項式只有常數項，計算迴圈不會執行，直接輸出初始值 `0`。

係數中的 `0` 也必須保留，因為它的位置會影響其他項對應的次方。

## 個人建議

- 這題最容易被騙到的就是微分，在實作上其實很簡單，這題考驗的是一些STL的用法如果會用，可以大幅減少代碼長度與實作難度。
