# UVa 10268 - 498-bis

## 題目連結

- [UVa 10268 - 498-bis](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&category=14&page=show_problem&problem=1209)

## 題意摘要

給定一個整數 `x` 與多項式的係數，求該多項式微分後在 `x` 的值。

係數依照次方由高到低排列，最後一個係數為常數項。例如係數 `1 1 1` 代表 `x² + x + 1`，微分後為 `2x + 1`；當 `x = 2` 時，答案為 `5`。

## 輸入說明

1. 每兩行為一組測資，第一行輸入整數 `x`。
2. 第二行輸入多項式的整數係數，依最高次項到常數項排列。
3. 所有輸入與輸出數值的絕對值皆小於 `2^31`。
4. 持續讀取直到檔案結束（EOF）。

## 輸出說明

- 每筆測資輸出多項式微分後在指定 `x` 的值，各占一行。

## 備註

- 微積分只用到微分的觀念，只需依據題目摘要的做法做微分就可以解決此題的微分運算。
